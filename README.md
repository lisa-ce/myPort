

# Lisa Chikovore Personal Portfolio Website

A modern, responsive personal portfolio website showcasing my work as a Full Stack Web Developer.

This portfolio highlights my projects, certifications, blog articles, volunteering experience, and contact information  all built with clean UI and smooth user experience in mind.Above all i was going for simplicity



## Live Preview

You can view the live version here:
https://lisachikovore.netlify.app/

## Features

* Introductory page with my initials landing animation (LC initials splash screen)
* Fully responsive design to any screen
* Mobile hamburger navigation
* Featured projects section
* Blog articles preview (linked to Medium)
* Speaking & volunteering highlights
* Social media and contact links
* Clean and minimal UI using modern CSS



## Built With

* **HTML5**
* **CSS3**
* **Vanilla JavaScript**
* [Font Awesome](https://fontawesome.com/) for icons
* Google Fonts (Inter & Cormorant Garamond)
